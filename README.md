# Crumbs & Co. Bakery Shop

A modern bakery shop website built with PHP and MySQL.

## Features

- User Authentication System
- Product Catalog
- Shopping Cart
- Order Management
- Admin Panel
- Responsive Design

## Requirements

- PHP 7.4 or higher
- MySQL 5.7 or higher
- Apache/Nginx web server
- Composer (for dependency management)

## Installation

1. Clone the repository
2. Create a MySQL database named `crumbs_co`
3. Import the database schema from `database/schema.sql`
4. Configure database connection in `config/database.php`
5. Start your web server
6. Access the website through your browser

## Directory Structure

```
crumbs-co/
├── admin/              # Admin panel files
├── assets/            # CSS, JS, and images
├── config/            # Configuration files
├── database/          # Database schema and migrations
├── includes/          # PHP helper functions and classes
├── templates/         # Reusable PHP templates
└── vendor/            # Composer dependencies
```
